# prealpha v1.5 builds

Future builds must follow [AGENTS.md](AGENTS.md): use `우정회관 키우기` for the app display name and EXE/APK filenames.

Build outputs, the pinned source snapshot, SDK tools and logs are in `prealpha-v1.5/` and `tools/`.
They are ignored by Git. Never upload `tools/debug.keystore` or the tools/log folders as release assets.

See `prealpha-v1.5/README.md` for the build commands and GitHub release steps.
